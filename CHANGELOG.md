## v0.4.2-alpha Release Candidate Hardening

- Readiness is computed once: single fail-closed `compute_publication_ready()`
  shared by report, JSON, terminal summary, and exit code. Critical-domain
  NOT_EVALUABLE always blocks; PASS_WITH_WARNINGS remains non-blocking.
- Exit-code contract: 0 = success / gate passed, 2 = gate not satisfied
  (PUBLICATION_READY mode), 3 = invalid input, 4 = internal error.
- Freshness binding (anti-stale-audit): `figure_audit.json` now emits
  `audited_artifacts` — SHA-256 + byte size of every audited input file
  (audit outputs excluded). Orchestrators must recompute hashes before
  consuming the audit; any mismatch or missing file = AUDIT_STALE.
- New `scripts/lib/sha256.R`: pure-R SHA-256 (FIPS 180-4) fallback so the
  binding works without `digest`/`openssl`; `digest` fast path preferred.
- JSON serializer hardened: `jsonlite::toJSON(auto_unbox = TRUE)` primary
  path; pure-R fallback now escapes backslashes, quotes, control characters,
  and non-ASCII (previously only quotes — Windows paths produced invalid
  JSON); NA/NULL serialize as null.
- New regression suite `tests/run_binding_serializer_tests.R` (23 checks:
  SHA-256 known vectors, adversarial escaping roundtrip, binding E2E
  incl. tamper → stale and delete → missing).
- Release validation unified: `scripts/run_release_validation.R` runs 11
  suites + packaging validator into `validation/latest_validation.json`
  (single machine source); reports regenerated by
  `scripts/generate_validation_report.R`.
- Documentation unified to v0.4.2-alpha: README (exit codes, fail-closed
  examples, regression counts), READINESS_POLICY (COLOR added to critical
  domains), stale packaging compliance report archived to
  `validation/history/`.
- No scientific, statistical, visual, or color rules changed.

## v0.4.1-alpha R6 Gate Semantics & Report Consolidation Patch

- Separated figure integrity from publication-package readiness:
  `FIGURE_INTEGRITY_STATUS` (SCIENTIFIC/STATISTICAL/CLAIM_EVIDENCE/
  PANEL_ARCHITECTURE/VISUAL/COLOR) vs `PUBLICATION_PACKAGE_STATUS`
  (GLOBAL_COHERENCE/DELIVERY/SOURCE_DATA/EXPORT_FORMATS/DELIVERY_METADATA/
  SESSION_METADATA/PROVENANCE/REPRODUCIBILITY).
- Distinguish `INCOMPLETE` (missing delivery material, not a figure error)
  from `FAIL` (declared-but-wrong): missing PDF/SVG/TIFF/metadata →
  INCOMPLETE; hash mismatch/DPI contradiction → FAIL.
- Added three audit modes with auto-selection:
  `QUICK_REVIEW` (image only), `SCIENTIFIC_FIGURE_AUDIT` (default),
  `PUBLICATION_READY` (strictest, fail-closed).
  `--mode` accepts both `--mode X` and `--mode=X`.
- Added `RULE_EVIDENCE_AGGREGATION`: one final status per rule across
  declarative/raster/vision evidence (confirmed contradiction > missing
  evidence > supportive evidence); final statuses include
  `PASS_WITH_LIMITED_EVIDENCE`.
- Global Figure State missing no longer forces FIGURE_INTEGRITY FAIL in
  non-PUBLICATION_READY modes (coherence evidence missing != violation);
  PUBLICATION_READY mode keeps GFS missing as BLOCKER (fail-closed).
- New report structure: Executive Summary (Figure Integrity / Publication
  Package / Final Readiness), What Passed / What Needs Revision /
  What Is Missing For Publication Delivery, grouped Top Issues, and
  Recommended Repairs grouped by owner (STATISTICS/FIGURE_GENERATOR/
  DELIVERY/USER...).
- Added machine-readable JSON fields: `audit_mode`, `figure_integrity`,
  `publication_package`, `publication_ready`, `repair_routes`,
  `aggregated_rules`, `raw_evidence`; old `PUBLICATION_READY` field kept
  for backward compatibility.
- Repair routing: FIGURE_INTEGRITY PASS + PACKAGE INCOMPLETE →
  `NEXT_ACTION=COMPLETE_DELIVERY` (never REGENERATE_FIGURE); scientific
  blocker → `RETURN_TO_FIGURE`; repair radius stays local.
- Empty-finding-message validator: every finding must carry a non-empty
  issue (new_finding rejects blank messages).
- QUICK_REVIEW: image-only VISUAL/COLOR evaluated via raster metrics
  (palette fragmentation / saturation); SCIENTIFIC stays NOT_EVALUABLE
  (never fabricated).
- Preserved: scientific rules, COLOR-01..14 logic (incl. COLOR-13 gray
  residue, COLOR-14 symbol semantics), fail-closed PUBLICATION_READY,
  max_auto_repair_rounds <= 3.
- Added `tests/run_r6_tests.R` (gate semantics 8 + audit modes 6 + evidence
  aggregation 8) and `tests/run_r6_real_regression.R` (A/C/B real figures).

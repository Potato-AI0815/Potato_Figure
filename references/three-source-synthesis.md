# Three-source synthesis

Potato Figure v0.2 separates three previously conflated figure skills.

## 1. Publication-figure discipline

Use for technical acceptability, editable output, accessible colour, legible text, image integrity, Source Data, provenance, and final-size QA.

This layer does not decide what the hero evidence is or make a figure aesthetically strong by itself.

## 2. Manuscript main-figure design

Use for one central claim, evidence hierarchy, a visually dominant hero panel, asymmetric mixed-modality composition, compact support panels, and deletion of redundant evidence.

This layer should normally produce a designed composite figure from independently auditable panels.

## 3. Dissertation and long-form figure governance

Use for chapter-level rhythm, repeated visual semantics, main-versus-supplementary routing, negative-result retention, image-plus-quantification sequencing, and reference-first candidate comparison.

This layer must not force every thesis figure to imitate a high-impact journal main figure.

## Shared decision order

```text
scientific question and boundaries
→ evidence role and hierarchy
→ figure grammar
→ visual art direction
→ selected visual, authoring, and journal profiles
→ render
→ scientific audit
→ delivery QA
→ visual QA
```

Profile-specific typography and colour values provide implementation consistency after the design decision. Mandatory colour and legibility principles remain independent of any particular palette, font, or authoring canvas.

When a user explicitly approves a real reference figure, the reverse-engineered visual profile takes precedence over the generic fallback theme and palette. Freeze only observable visual properties; never infer missing scientific labels or redistribute the reference asset without permission.
